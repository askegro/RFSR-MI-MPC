# Simulation — RFSR-MI-MPC closed-loop campaigns

This folder contains the five simulation campaigns used in:

> A. Škegro, Q. Ouyang, T. Wik, C. Zou,
> *RFSR-MI-MPC: Ranking-Based Feasible-Set Restriction for Real-Time Control of
> Reconfigurable Battery Packs*,
> submitted to IEEE Transactions on Control Systems Technology.

Each campaign simulates a 20-cell series-connected reconfigurable battery pack
with per-cell bypass switching in closed loop, solving a mixed-integer convex MPC
problem at every 1 s sampling instant. Postprocessing, table generation and
figure generation are in `../postProcess/` and `../figureGeneration/`; see the
repository root README.

---

## Campaigns

| Runner | Result file | Feeds |
|---|---|---|
| `run_nominal_wltc.m` | `Results_nominal_wltc_<date>.mat` | Table III, Table V, Figs. 2–4, Sections VI-A.1 and VI-A.3, Appendix |
| `run_samestate_proposed.m` | `Results_samestate_proposed_<date>.mat` | Table IV, column 1 |
| `run_samestate_rulebased.m` | `Results_samestate_rulebased_<date>.mat` | Table IV, column 2 |
| `run_montecarlo_ics.m` | `Results_montecarlo_ics_<date>.mat` | Table VI, Section VI-B.1 |
| `run_robustness_sweeps.m` | `Results_robustness_sweeps_<date>.mat` | Table VII, Sections VI-B.2 to VI-B.4 |

**`run_nominal_wltc`** — both controllers over one scaled WLTC Class 3 cycle
(1800 active control steps), logging per-step solver time, branch-and-bound node
count, solve classification and closed-loop performance.

**`run_samestate_proposed`** — drives the plant with the proposed controller under
the 1 s operational limit and, at every active state visited, additionally solves
the full subset-selection formulation from the same pre-control state with a
100 s reference limit. Isolates the objective cost of the restriction from
trajectory divergence.

**`run_samestate_rulebased`** — the same paired solves on a trajectory generated by
a deterministic rule-based driver that cyclically shifts the engagement set. The
driver uses neither SOC, SOH nor the ranking score, so the states are
out-of-policy for both controllers.

**`run_montecarlo_ics`** — 20 independently sampled initial SOC/SOH realizations,
both controllers started from the same sampled pack state within each
realization. Uses `parfor`.

**`run_robustness_sweeps`** — cell heterogeneity and demand (4 cases), pack size
(N = 16/20/24) and prediction horizon (N_p = 4/6/8/10). Uses `parfor`.

## Requirements

- MATLAB R2025b or later (earlier versions may work but have not been tested)
- [YALMIP](https://yalmip.github.io/) and [Gurobi](https://www.gurobi.com/) 13.0.1
- Parallel Computing Toolbox — required only by `run_montecarlo_ics` and
  `run_robustness_sweeps`

## Quick start

All five campaigns, in order:

```matlab
cd mainSimulationRunners
RUN_ALL_SIMULATIONS          % default worker count
RUN_ALL_SIMULATIONS(8)       % or set it explicitly
```

A single campaign:

```matlab
cd mainSimulationRunners
run_nominal_wltc
```

## Output

Each run writes one timestamped `.mat` into `../results/`. Postprocessing always
picks up the most recent matching file, so earlier results are never overwritten.
`run_nominal_wltc` saves `Results` (per variant), `cfg` and `variants`;
`run_robustness_sweeps` saves its sweep struct as `RobResults`.

## Reproducibility

`run_nominal_wltc` seeds the global RNG at `1337` (Mersenne Twister) and uses
separate Threefry streams seeded at `42` (SOH sampling) and `4242` (SOC
sampling). `run_montecarlo_ics` offsets all three per realization
(`1337+r-1`, `42+r-1`, `4242+r-1`), so each realization is independently
reproducible regardless of worker assignment order. Gurobi is run with
`Seed = 42` and `MIPGap = 1e-4`. Bootstrap intervals in postprocessing use fixed
seeds.

The published results were produced with MATLAB R2025b and Gurobi 13.0.1 on an
Intel Core i7-1370P (13th Gen).

## Cell model

Nominal electrical, thermal and ageing parameters are for a **Sony/Murata
US26650FTC1** LFP cell (3.0 Ah nominal), defined in `../data/LFPChemistry.m`.
The models are adopted from the sources below without re-identification of
parameters:

**Cell specification:**
> Murata US26650FTC1A Product Specification, January 2019.

**Calendar and cycle ageing model:**
> Xu, L. et al. Calendar aging and cycling aging models. *Nature Communications*
> **14**, 119 (2023).
